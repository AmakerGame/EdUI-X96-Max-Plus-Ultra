# Перший сценарій: встановлення EdUI на SlimBOXTV 49

## Передумови

- Пристрій X96 Max Plus Ultra на прошивці **SlimBOXTV 49**.
- Встановлений **Magisk** (root). Якщо root ще немає — спочатку встановіть Magisk за стандартною інструкцією для цієї прошивки.
- Пристрій підключений до **інтернету** (Wi-Fi або Ethernet).
- Заряджений блок живлення; **не вимикати приставку** до завершення.

## Кроки

1. Завантажте `EdUIInstaller.apk` зі сторінки **Releases** цього репозиторію (будь-який Release — Installer однаковий).
2. Встановіть APK (файловий менеджер / «Встановити через ADB» — як зручніше).
3. Запустіть **EdUI Installer**.
4. Натисніть **«Встановити EdUI»**.
5. На запит **Root** в Magisk натисніть **«Надати»**.
6. Installer покаже прогрес: перевірка → завантаження → перевірка пакета → прошивка розділів.
7. Після завершення пристрій **сам перезавантажиться**.
8. Після завантаження — EdUI. Ваша стрічка застосунків, налаштування Wi-Fi, акаунти та файли **збережені**.

## Якщо щось пішло не так

- **«Потрібен Root-доступ»** — надайте Root у Magisk і повторіть.
- **Помилка мережі** — перевірте інтернет, повторіть.
- **Помилка SHA-256 / версії** — пакет пошкоджений або не той Release; повторіть завантаження.
- **Пристрій не завантажився після прошивки** — прошийте повний образ `edui_x96maxplusultra_firmware_amlv2.img` через **USB Burning Tool** на ПК (крайній випадок; зазвичай не потрібен).
