# Сценарій: перевірка та встановлення оновлення EdUI

## Штатний запуск EdUIUpdate

Єдиний спосіб відкрити екран оновлення:

```
Налаштування
→ Про пристрій
→ Перевірити оновлення
```

Після натискання відкривається **повноекранна Activity EdUIUpdate** — частина системи EdUI (не сторонній застосунок, без іконки в лаунчері).

## Що відбувається

1. Екран показує **поточну версію** EdUI.
2. Виконується **один** запит до GitHub Releases (останній Release репозиторію).
3. Порівняння поточної версії з версією Release (Git tag).

### Оновлення немає

```
Ви використовуєте останню версію EdUI
Поточна версія: EdUI vX.Y.Z
```

Кнопка **«Назад»** повертає до Налаштувань.

### Оновлення є

```
Доступне оновлення

Поточна: EdUI vX.Y.Z
Нова: EdUI vX.Y.Z+1
<що нового з Release>

[ Встановити EdUI vX.Y.Z+1 ]
```

## Встановлення

1. Натисніть **«Встановити»**.
2. Завантажується `update.zip` відповідного Release (з прогресом).
3. Перевірка цілісності (SHA-256, manifest, версія).
4. Прошивка розділів зі списку manifest.
5. Автоматичне перезавантаження → нова версія EdUI.

**Root не потрібен** — EdUIUpdate має системні права, вшиті в прошивку.

## Теми

EdUIUpdate автоматично підлаштовується під системну тему (світла/темна) — окремого перемикача немає.

## Дані

Оновлення **не видаляє** користувацькі дані: жодного wipe, userdata не чіпається, програми та налаштування зберігаються.
