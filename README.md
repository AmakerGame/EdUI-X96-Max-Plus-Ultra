# EdUI для X96 Max Plus Ultra

**EdUI** — кастомна прошивка для ТВ-приставки **X96 Max Plus Ultra** (SoC Amlogic SC2 / S905X4), побудована на базі **SlimBOXTV 49** (Android 11, API 30).

Прошивка орієнтована на українського користувача: українська локалізація системи та лаунчера, видалені російськомовні застосунки, розблокований завантажувач (AVB вимкнено, `flash.locked=0`, `verifiedbootstate=orange`), максимальне логування ядра, вбудовані інструменти керування системою в Налаштуваннях.

## Можливості EdUI

- **Повністю українська система** — налаштування, лаунчер (Google TV Launcher), системні рядки.
- **Без російських застосунків** — видалено Zona, Xplore, RuStore/VK, Yandex Browser, FMPLAY, KinoTrend, TorrServe, VimuMediaPlayer, AirReceiver, ByeByeDPI, SoundAmplifier тощо.
- **EdUI — X96MPU** — розділ у *Налаштування → Про пристрій*:
  - **Стан системи та пристрою** — модель (X96MPU v1), Android, білд, fingerprint, плата, версія/стан/слот/serial завантажувача, локаль, dm-verity.
  - **Керування завантажувачем** — резервна копія/відновлення U-Boot env, перезавантаження, режим оновлення.
- **«Перевірити оновлення»** — системний компонент **EdUIUpdate** для оновлення прошивки без ПК.
- **LeanKeyboardF** — українська екранна клавіатура за замовчуванням.
- **Розблокований завантажувач** — A/B-слот `boot_b` вільний для сервісних образів; AVB-вимкнення та max logging реалізовані через U-Boot env (оборотно, без перепрошивки коду).
- **Виправлені баги** — усунуто періодичний краш `SBXcustomizer` (`Resources.NotFoundException` у `ConfigurationProvider`), краші Settings через неіснуючі Intent.

## Встановлення EdUI (перше)

EdUI встановлюється **без ПК, без USB-кабелю, без factory reset** — за допомогою **EdUIInstaller.apk**.

### Сценарій

1. На пристрої зі **SlimBOXTV 49** встановіть `EdUIInstaller.apk` (файл зі сторінки Releases).
2. Запустіть **EdUI Installer** → натисніть **«Встановити EdUI»**.
3. Дозвольте **Root (Magisk)** коли буде запит.
4. Installer автоматично:
   - отримує інформацію про останній Release з GitHub;
   - завантажує `update.zip`;
   - перевіряє цілісність (SHA-256, структура ZIP, відповідність версії);
   - розпаковує та прошиває **тільки необхідні розділи** (`system_a`, `system_ext_a`);
   - **не чіпає userdata, не робить wipe, не видаляє програми**;
   - перезавантажує пристрій.
5. Після перезавантаження працює EdUI.

> Під час прошивання не вимикайте приставку та не натискайте кнопки пульта.

## Оновлення EdUI

Після встановлення EdUI оновлення виконується системним компонентом **EdUIUpdate**.

### Точний шлях

```
Налаштування
→ Про пристрій
→ Перевірити оновлення
→ Activity EdUIUpdate
```

### Сценарій

1. Відкривається повноекранний системний екран **«Оновлення EdUI»** (тема світла/темна — автоматично за системою).
2. EdUIUpdate визначає поточну версію (versionName компонента = версія EdUI) і останній GitHub Release.
3. Якщо оновлення немає → «Ви використовуєте останню версію EdUI» + номер версії.
4. Якщо є → «Доступне оновлення»: поточна/нова версія, що нового, кнопка **«Встановити»**.
5. Після підтвердження: завантаження `update.zip` → перевірка → прошивка розділів → автоматичне перезавантаження.

**EdUIUpdate не працює у фоні**, не перевіряє GitHub без дії користувача, не має іконки в лаунчері та не потребує Root для кожного оновлення (системні привілеї вбудовані в прошивку).

## Структура Release

Кожен GitHub Release (tag `vX.Y.Z`) — **самодостатній повний комплект** і містить **усі 4 файли**, навіть якщо деякі не змінились:

| Файл | Призначення |
|---|---|
| `update.zip` | Автоматичне встановлення/оновлення (використовується Installer та Update) |
| `edui_x96maxplusultra_firmware_amlv2.img` | Повний Amlogic-образ для прошивки через USB Burning Tool (відновлення/перше встановлення) |
| `EdUIUpdate.apk` | Системний компонент оновлення (вже вшитий у прошивку; файл — для довідки/відновлення) |
| `EdUIInstaller.apk` | Програма первинного встановлення EdUI на стокову прошивку |

Версія Git tag = версія Release = `versionName` прошивки EdUI.

## Структура update.zip

```
update.zip
├── manifest.json
│   {"version":"1.0.0","files":[
│     {"partition":"system_a","image":"system_a.img","sha256":"…","size":…},
│     {"partition":"system_ext_a","image":"system_ext_a.img","sha256":"…","size":…}]}
├── system_a.img        — повний ext4-образ розділу system_a
└── system_ext_a.img    — повний ext4-образ розділу system_ext_a
```

Прошиваються **тільки розділи зі списку manifest** — жодних зайвих записів. `userdata`, `cache`, `boot`, `vendor`, `product`, `odm` не чіпаються.

## Сумісність

- **Пристрій:** X96 Max Plus Ultra (SC2 / S905X4, Android 11)
- **Базова прошивка:** SlimBOXTV 49
- **Root:** Magisk 24.x (потрібен лише для EdUIInstaller; у EdUI — вшиті системні права)

## Відомі особливості

- Wi-Fi (чіп W150S1): періодичні `wifi_mac_scan_timeout` / `WifiVendorHal` stats-помилки — обмеження драйвера, не впливає на роботу EdUI.
- `tee_rpmb_init Verify key failed` — відсутнє factory-провіжнування RPMB/eFuse; не лікується прошивкою.
- Під час прошивки уникайте вимкнення живлення.

## Ліцензія та підтримка

Прошивка надається «як є». Базова система — SlimBOXTV (Android Open Source Project, Android 11).
